# Project Agent Instructions

Read [`labs/shared/AGENTS.md`](labs/shared/AGENTS.md) for every task in this repository.

Read the specialist guide that matches the files being changed:

- Novel prose, story planning, notes, source material, or the table of contents: [`labs/writing/SKILL.md`](labs/writing/SKILL.md)
- Voice renders, pronunciation, audio QA, or audiobook delivery: [`labs/audiobook/SKILL.md`](labs/audiobook/SKILL.md)
- Comic scripts, visual continuity, panel plans, or art prompts: [`labs/comics/SKILL.md`](labs/comics/SKILL.md)

For cross-team work, read all applicable specialist guides before editing. These guides define how agents work; the story and character files define what is true.

For multi-section or multi-chapter work, also read [`labs/batches/README.md`](labs/batches/README.md) and use a batch manifest rather than inventing a one-off aggregation method.
